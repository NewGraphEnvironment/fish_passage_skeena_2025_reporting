# fish_passage_skeena_2025_reporting 0.0.1 (2026-08-03)

* Establish the Skeena 2025 report, spawned from `fish_passage_fraser_2025_reporting` at `7ef34cc` so it inherits that report's thematic appendix structure, eDNA appendix and effectiveness-monitoring memo pattern. Prior Skeena reporting (`fish_passage_skeena_2024_reporting`) has neither, and the shared reporting template is structurally behind both.
* Retarget the report to the Skeena: watershed groups BULK, MORR, ZYMO, KISP and KLUM, the `sern_skeena_2023` collaborative GIS project, and steelhead as the modelled species in place of the Fraser's bull trout. Steelhead follows the 2024 Skeena report and drives which habitat model is pulled, the gradient thresholds applied, and the symbology on every site map.
* Declare `force_bcfishpass_rebuild` in the parameter block. The data loader reads it to decide whether to rebuild the habitat model cache, but it had never been declared, so it resolved to `NULL` on every build — a flag that existed in the code and nowhere the reader could see it.
